## 1. Задача 18: меню по щелчку на имени файла

### Как было

В панели скана после «42 из 54» стоит подпись листа (`sheetLabel` в
`src/scan.tsx`, `.scanname`): имя файла, у PDF — «имя.pdf · стр. N». Щелчок
по ней ничего не делает.

### Что делаем

1. Подпись листа становится кнопкой (`data-scan-file-menu`): при наведении —
   курсор-рука и подчёркивание; щелчок не уводит курсор из поля формы (как
   остальные кнопки панели, `onMouseDown preventDefault`).
2. Щелчок открывает меню под подписью из двух пунктов:
   - «Показать в папке» — папка листа в проводнике (на Mac — в Finder),
     файл выделен; как «Показать в папке» в «ⓘ О программе»;
   - «Открыть во внешней программе» — файл в программе, назначенной в
     системе для этого типа (Windows — как двойной щелчок в проводнике, Mac —
     `open`).
3. Меню закрывается после выбора пункта, щелчком мимо и по Esc. Esc в меню
   не уходит дальше (не закрывает экран, не трогает поле формы).
4. Лист PDF («имя.pdf#N») — показывается и открывается сам файл PDF (номер
   страницы внешней программе не передаётся). TIFF — исходный файл, не
   картинка из кэша.
5. Работает и в основном окне, и в отдельном окне скана; при показе
   чужого листа (правка, «скан» из «Поиска», запись другого года) — тот файл,
   что показан сейчас, из его папки.
6. Нет файла (лист «нет файла», папка не открыта) — подписи-кнопки нет, как
   и сейчас подписи нет.
7. Отказ (файл пропал, система не открыла) — жёлтая полоса с причиной через
   `report()`, не молчание.

### Защита

Окно не передаёт в Rust произвольный путь. Новые команды
`scan_reveal(dir, name)` и `scan_open_external(dir, name)`:
- папка — только разрешённая окну (`Sheets::allow`, как у протокола `scan`);
- имя — без разделителей пути, после отрезания «#N» — скан
  (`scans::is_scan`: jpg, jpeg, png, tif, tiff, pdf);
- файл существует.

Сборка пути и проверки — чистая функция крейта (`scans::sheet_file`), с
тестом: чужая папка, «..\\», «a/b.jpg», «x.exe», «имя.pdf#3» → «имя.pdf».
Открытие файла — только для этих расширений, поэтому исполняемый файл
команда не запустит.

### Как проверить

- Тест крейта `sheet_file` (выше).
- Стенд: щелчок по имени — меню; Esc и щелчок мимо закрывают; курсор
  остаётся в поле формы; в шиме команды пишут вызов в журнал стенда.
- e2e Windows: `scan_open_external` с папкой, не разрешённой окну, и с
  «x.exe» — отказ (сам запуск программы на раннере не проверяем).
- Руками (Роман, Олег, Нинель на Mac): папка с выделенным файлом и
  просмотрщик.

## 2. Долг п. 27: «↩ к набору» приметнее

Кнопка есть, пока показан лист по ссылке «скан» (`away === "link"`); она
мелкая, как остальные кнопки панели. Высота формы и панели — дефицит,
новой строки не добавляем.

Предложение: пока показан чужой лист, кнопка залита основным цветом (как
активная вкладка) и называется «↩ вернуться к набору»; рамка блока скана —
того же цвета. При правке записи (`away === "edit"`) рамка тоже цветная —
скан вернётся сам после «Отменить» или сохранения, кнопки нет, как сейчас.

Как проверить: стенд — «скан» из «Поиска»: кнопка залита, рамка цветная;
«↩ вернуться к набору» — рамка обычная.

## 3. Долг п. 28: «Чей родств.» — роли своего раздела

Перечень `kin_of` один на все разделы (`db/seed/lookup.csv`). Подсказка
«Чей родств.» (`Suggest kind="kin_of"`) получает отбор строк (новый проп
`only`):
- «Рождения» — без «поручителя №…», «жениха», «невесты»;
- «Браки» — без «восприемника №…», «отца», «матери».

Своё вписанное значение и значения, которые люди добавили сами, остаются
(отбор убирает только чужие роли поставки). Набранные записи не меняются.

Как проверить: стенд — «Рождения» и «Браки»: ▾ «Чей родств.» — только свои
роли; вписанное «крёстной» сохраняется.

## 4. Долг п. 29: «Стр.» за переходом на кадр по номеру

Листание на один файл зовёт подписчиков `onTurn` — форма двигает «Стр.»
(`turnPage`). Переход по номеру (`leaveNo` → `goTo`) их не зовёт.

Делаем: номер, набранный в поле кадра и подтверждённый Enter, двигает «Стр.»
так, как если бы до кадра долистали стрелками — `turnPage` столько раз,
на сколько кадров переход (назад — с −1). Те же условия, что у листания:
только новая запись, только видимая форма, папка дела её года, не во время
показа чужого листа. Другие вызовы `goTo` (восстановление места, окно
скана по действиям главного) «Стр.» не трогают — только набранный номер.
В отдельном окне скана то же: его набранный номер приходит в главное окно
с отметкой «набран руками».

Как проверить: стенд — кадр 12, «Стр.» 5; в поле кадра «15» + Enter —
«Стр.» как после трёх «→»; «10» + Enter — как после пяти «←»; запись на
правке — «Стр.» не меняется.

## Что не меняется

Схема базы, выгрузки, импорт. Rust — две новые команды и функция крейта.
