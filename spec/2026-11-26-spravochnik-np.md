# Решение: справочник населённых пунктов

Из замысла: Бэклог задача 9 (замечание Романа 1 от 11.11.2026). 26.11.2026.

## Что делаем

1. На «ⓘ О программе» — блок «Справочник населённых пунктов»: число
   пунктов и сколько из них с пустыми полями; кнопка «Открыть справочник».
2. Окно справочника — список: название, тип, волость, уезд, губерния,
   ссылка Familio, записей с этим пунктом. Одна строка на
   название — лучшая строка по правилу `place_find` (полное место, тип, не из
   архива, самая ранняя). Над таблицей — поле «найти» по названию и флажок
   «только с пустыми полями» (пуст тип, уезд, губерния, волость или ссылка
   Familio). Пустое поле названо словами: «нет волости», «нет ссылки
   Familio». Окно не шире колонки программы — строка в два яруса:
   «д. Зуево» и под ним «Нежитинская вол. · Буйский у. · …», справа число
   записей (запись с отцом и матерью из одного пункта — одна).
3. Щелчок по строке — та же карточка пункта на правку (`PlaceCard` с
   `existing` из `place_get`): правка, «Объединить с другим пунктом». После
   сохранения или объединения — снова справочник, строка обновлена; Esc в
   карточке — назад в справочник.
4. Справочник общий для приходов: правка разносится сверкой, как правка из
   формы. Схема базы не меняется, записи не трогаются.

## Почему так, а не иначе

- Вход — с «О программе», где уже стоят «Найти в записях» и «Запомненные
  написания»: верхняя строка окна занята целиком (грабли «Шрифт Inter»).
- Карточка — готовая, со всеми её правилами (название, тёзка, объединение);
  своей правки полей в таблице нет — второй путь записи в `place` разошёлся
  бы с карточкой.
- Число записей — по всем строкам с тем же названием (двойники одного
  пункта), одним запросом с группировкой, а не подзапросом на строку.
- Допущение: пунктов — сотни; таблица целиком, отбор в окне.

## Критерии приёмки

- В окне — все пункты, по одному на название; с флажком — только с пустыми
  полями; «найти» отбирает по названию.
- Щелчок — карточка этого пункта с его полями; сохранили волость — строка в
  справочнике с волостью, флажок «пустые поля» её больше не показывает (если
  остальное заполнено).
- Двойник без подробностей рядом с полным пунктом — одна строка, с полным.

## Как проверяется

- Тест крейта `places`: лучшая строка на название, число записей по
  двойникам, признак пустых полей.
- Стенд s106: блок, окно, флажок, поиск, карточка, сохранение, Esc.

## Чего сознательно не делаем

- Правку полей прямо в таблице, удаление пунктов (это «Найти
  неиспользуемые…»), выгрузку справочника.
